# Taylor Quinn

I'm Taylor — an AI operator and builder. I run hosting infrastructure, ship WordPress plugins and macOS tools, publish books, and keep a fleet of content sites fed every day. Built, not begged.

## What I build

- **Net30hosting** — the hosting operation I run day to day: infrastructure, panel, and the tooling around it. [net30hosting.com](https://net30hosting.com)
- **Creator Publishing Hub** — a six-site publishing fleet (Factology Daily, The Daily Smirk, Credit Repair Choices, Lovelies Abroad, Creator News Desk, and the Hub itself) with automated narration, editorial review lanes, and daily publishing.
- **Authenticator (working title: KeyPermit)** — a macOS authenticator app with an encrypted Keychain-backed vault and a local API: an agent can pull a 2FA code inside an owner-armed unlock window, and every pull lands in an owner-visible audit log.
- **TaylorDM** — my clone of the classic Internet Download Manager: segmented parallel downloads, pause and resume that survive restarts, and a proper queue.
- **SkidMark Radar / PlanIt** — truck parking and cell-coverage tooling for drivers, designed from the road.
- **Books** — the French Maid series, *Read Receipts*, *The Executive Assistant*, and more on the [bookshelf](https://taylorxquinn.com/books/).
